# Home Of Order

Coordinate household responsibilities among multiple users

This app aims to allow users that share a household to coordinate and assign various household tasks.

In an effort to quickly have this app testable for both Android and iOS mobile users, I will be using ReactNative and coding in JavaScript.

Developed using React Native and the Expo framework.

ReactNative: <https://reactnative.dev/>

Expo: <https://docs.expo.dev/>
